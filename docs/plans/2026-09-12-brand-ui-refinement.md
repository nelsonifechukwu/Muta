# Brand UI refinement

## Objective

Keep the approved open-book logo, speaking-dot icon, favicon, and startup lockup while restoring the product interface to the quieter neutral visual system that preceded the September rebrand rollout.

## Design boundary

- Brand artwork remains the source of identity.
- Terracotta remains the restrained interactive accent.
- Main surfaces return to warm paper in light mode and neutral charcoal/brown in dark mode.
- Product body and reading typography return to the established system stacks; display artwork remains outlined SVG and therefore renders consistently without changing interface typography.
- The same boundary applies to chat, visualization frames, landing pages, the experiment report, and the desktop splash so the product does not drift between surfaces.

## Acceptance

1. No forest-green wash in dark mode.
2. Light and dark chat views match the previous hierarchy and density while showing the approved logo.
3. Logo and native icon parity tests remain green.
4. Theme, UI, desktop, packaging, and full regression suites pass.
5. Both macOS offline packages are rebuilt from one immutable source revision and independently inspected before replacing the current test packages.
