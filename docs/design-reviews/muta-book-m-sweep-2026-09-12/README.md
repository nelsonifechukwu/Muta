# Muta — open-book logo exploration

## Active direction

The book stays a natural open book. Its curved pages and central valley may suggest M, but a
literal letter construction is not the goal. The earlier M-shaped experiments in this directory
were superseded by the user's clarification.

The user explained that the square beneath u carries pronunciation meaning in the Igbo name.
Preserve it with the wordmark and do not reinterpret it as a foothold or cube. In the newest
iteration, the user explicitly proposed using the square itself as the dialogue cue, and reusing
that shape beneath the standalone book.
Exact written spelling was requested; the current concepts retain the visible square under u.

## Current review boards

  beneath u into a compact speech mark, with the same motif beneath the standalone books.
  The pages stay clear. An initial longer tail was reduced so the square remains the dominant
  shape. The generated edit also slightly changed page height; it is not a pixel-exact edit.

- `c-two-tone-conversation.png`: closest to the reference; ivory and terracotta speech detail

- `a-book-conversation.png`: dark speech shape makes the conversation cue more prominent.
- `b-open-book.png`: natural book without the speech detail. The square remains under wordmark u.

All boards are 1536 × 1024 raster concepts generated with the built-in image tool. Each shows a
large wordmark/symbol composition, app icon, and one-color interpretation. These are visual
explorations, not exact vector masters or verified pixel-size icon exports. The serif lettering
is generated artwork, not a promised font file. Some rendered color variation remains.

## Review findings

An independent reviewer inspected the generated boards against the corrected brief. C was the
closest reference refinement; A gave the strongest conversation contrast; B was the calmest.
A and C use effectively the same app-icon treatment, so they should be compared primarily on
the full-logo speech treatment. The generator wrongly added extra squares beneath B's standalone
books; a targeted edit removed those while preserving the square beneath the wordmark u.

Before production, the selected direction needs a vector drawing pass with consistent curves,
exact lettering/under-u placement, flat color values, and 16/24/32 px tests. The square's position
must be optically tied to u, rather than centered under the word as a whole.
