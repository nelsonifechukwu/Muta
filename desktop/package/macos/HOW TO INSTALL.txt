HOW TO INSTALL MUTA ON macOS

This is an unsigned private test build. Only continue if you received this archive directly from
the Muta team.

1. Extract the complete archive.
2. Keep Muta.command, Muta.app, and model-pack together in the extracted folder.
3. Open Terminal.
4. Type `/bin/zsh ` including the space at the end.
5. Drag Muta.command from the extracted folder into the Terminal window, then press Return.

Running the command through Terminal avoids Finder's quarantine check on the helper. Muta.command
then removes download quarantine from this copy of Muta.app and opens it. Muta verifies and
installs the sibling offline model pack in the current user's Application Support. No internet
connection or separate model download is required.

A public Muta release must be Developer ID signed and notarized and will not need this workaround.
